과제물1: 산업연관표분석 웹앱
## 시나리오: 관광수요 회복에 따른 숙박·음식점 수요변화

### 1. 시나리오 배경
외국인 관광객 증가와 내수 관광 회복으로 숙박·음식점 부문의 최종수요가
늘어나는 상황을 가정한다.
숙박업은 생산유발액 중 수출 항목의 비중이 36.6%로, 대외 수요(관광 포함)의 영향이 상대적으로 큰 부문이다.
충격 금액(100억 원)은 분석을 위한 가정값이다.

### 2. 충격 설정 (단위: 백만원)
| 부문 | 코드 | 수요 증가액 |
|---|---|---|
| 숙박 | 5820 | 4,000 |
| 일반음식점 | 5811 | 4,000 |
| 기타음식점 | 5812 | 2,000 |
| 합계 | | 10,000 (100억 원) |

- 기준 자료: 2023년 투입산출표, 생산자가격, 기본부문(380개)
- 분석 방법: 앱의 "파급효과 계산" 기능 (생산유발·수입유발·부가가치유발)
본 결과에서 부가가치유발액과 수입유발액의 합이 수요 증가액과 일치함을 확인하였다.

### 3. 분석 결과 (단위: 백만원)
| 지표 | 값 |
|---|---|
| 수요 증가액 | 10,000 |
| 생산유발액 | 21,647.3 |
| 수입유발액 | 1,764.4 |
| 부가가치유발액 | 8,235.6 |

생산유발액 상위 산업:

| 순위 | 산업 | 생산유발액 |
|---|---|---|
| 1 | 일반음식점 | 4,191.6 |
| 2 | 숙박 | 4,016.5 |
| 3 | 기타음식점 | 2,011.8 |
| 4 | 도소매 및 상품중개서비스 | 1,164.7 |
| 5 | 비주거용 건물 임대 | 495.6 |
| 6 | 시장조사 및 경영지원서비스 | 454.2 |

### 4. 해석
- 수요가 100억 원 늘어나자 경제 전체 생산은 약 216억 원 늘어
  생산유발 승수는 약 2.16배(21,647.3 ÷ 10,000)이다.
- 부가가치유발액은 약 82억 원(수요 증가액의 82.4%)이고,
  수입유발액은 약 18억 원(17.6%)이다.
- 충격을 준 세 부문(숙박, 일반음식점, 기타음식점)이 생산유발의
  약 47%를 차지하고, 나머지 약 53%는 다른 산업으로 퍼졌다.
- 도소매, 건물 임대, 경영지원서비스 등이 상위에 나타나, 관광 소비가
  유통과 사업서비스 부문의 생산까지 늘린다는 것을 알 수 있다.

### 5. 한계
가격이 변하지 않는다고 가정한 수요 주도 모형이며, 단기 정태 분석이다.
공급 제약, 가격 변화, 고용 효과는 반영하지 않았다.

### 6. 웹앱의 특징
서버 없이 브라우저에서 실행: Pyodide(WebAssembly 기반 Python)로 산업연관분석을
  브라우저에서 직접 계산하므로 별도 서버 설치가 필요 없다.
원자료 탐색: 2023년 투입산출표의 12개 원자료 시트를 열어, 부문 코드와
  부문명으로 검색하며 항목별 값을 확인할 수 있다. (금액 단위: 백만원)
380개 기본부문 수요충격 분석: 부문별 수요 증가액을 입력하면 생산유발액,
  수입유발액, 부가가치유발액과 생산유발 상위 15개 산업이 표시된다.
  
### 7. 웹앱의 장점
별도 프로그램 설치 없이 웹 주소만으로 누구나 접속해 사용할 수 있다.
원자료와 분석 결과가 같은 화면 체계(같은 부문 코드, 같은 단위)로 연결되어
결과를 원자료와 대조하며 해석하기 쉽다.
입력값을 바꾸면 즉시 다시 계산되어 여러 시나리오를 빠르게 비교할 수 있다.
### 8. 향후 활용 방안
관광, 수출, 투자 등 다양한 수요충격 시나리오의 파급효과 추정
- 같은 금액을 여러 부문에 투입했을 때의 생산·부가가치유발 효과 비교
- 새 연도 투입산출표 반영과 소분류·중분류·대분류별 분석으로 확장
